# 聚水潭正式环境接口开通清单

更新日期：2026-11-24。2026-10-22的沙箱与发布记录保留在下方，当前流程以本节和[聚水潭对接说明](JUSHUITAN.md)最新日期规则为准。
用途：正式应用上线时统一申请权限、核对授权并逐项验收。

当前国内普通销售订单正式提交后独立发起飞书审批和聚水潭账期推单，财务在ERP审核；CRM继续读取出库和物流，不把账期挂账计为实收。既有全款发货流程保留。

指定物流新增条件依赖 `/open/logisticscompany/query`：CRM及源码网关已接入；现有正式网关已支持，2026-11-24按仓库15136229只读返回12项配置。默认由仓库安排不读取此目录。指定公司真实上传仍需业务验收；本地测试不代表生产已发布本次物流表单更新。

**沙箱成功不代表正式权限已开通。下方2026-10-22正式状态为历史记录，不覆盖最新只读核验或独立发布记录。**

## 当前系统进度（2026-10-22）

- **代码已发布生产并推送GitHub**：提交 `00e9b7d`，生产CRM已包含提交发货、地址/备注修改、关联变更单、差额流水及物流回传能力。
- **沙箱主流程已通过**：上传与查单、连续改址、备注回查、取消重建、补收/退款登记、原单及原流水保留、拆单、部分/全部发货、两包裹运单回传、外部发货回传。收退款只登记流水，不执行真实资金划转。
- **厂商反馈关闭两项边界**：接口不支持撤销已出库单；取消单中的内容不影响业务计算。依据用户转述聚水潭反馈关闭，不记作撤销回传或资金报表端到端实测通过。详见[验收记录](JUSHUITAN-ACCEPTANCE-2026-10-21.json)。
- **正式连接尚未启用**：生产CRM未配置正式聚水潭连接；现有云网关仍用于sandbox。正式应用权限、授权公司、店铺、SKU、出口白名单及正式端到端联调待核对。
- **使用入口**：已提交订单在原单“发货详情”修改地址/备注；商品、数量、金额用“变更商品与金额”生成关联变更单，不覆盖原单历史。已拆分、合并或已出库订单由现有限制拦截，转人工处理。

正式申请总览：**10项必需（基础7项＋改单3项），2项辅助可选**。拆单和发货写接口仅为沙箱仓库验收使用，不是当前生产CRM的调用依赖。

## 6. 正式上线逐项验收（尚未执行）

正式上线需单独安排，本清单不是上线执行记录。

1. 店铺查询成功，并确认属于正确的正式ERP公司和店铺。
2. 普通商品资料查询返回启用的正式SKU及款式编码。
3. 库存查询成功，核对仓库和库存口径；空列表与无权限分别处理。
4. 用经授权的正式小额订单验证上传；同时检查顶层code及每单issuccess/o_id。
5. 按上传返回的同一单号查询核对，确认没有重复建单。
6. 由正常仓库流程完成约定的发货，再验证销售出库数量、拆单和运单信息回到CRM。
7. 在正式测试单上验证改址、备注、旧单取消及关联变更重建；补收/退款按真实业务审批登记。
8. 如启用辅助接口，分别验证店铺商品查询及发货信息查询；结果为空不自动当成失败。
9. 核对失败/超时查单、权限不足与频率限制提示；正式联调完成后更新下方记录。
